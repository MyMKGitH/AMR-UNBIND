# Optional local AutoDock Vina executable

Place a compatible Vina binary here, if not present already, when the Python `vina` package is unavailable:

- Windows: `vina.exe`
- Linux/macOS: `vina`

AMR-UNBIND searches `AMR_UNBIND_VINA`, this directory, the project root, and `PATH`.
